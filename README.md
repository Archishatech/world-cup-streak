# World Cup Streak

An interactive web app to track and analyze FIFA World Cup streaks.

## Installation
1. Clone the repo: `git clone https://github.com/Archishatech/world-cup-streak.git`
2. Install dependencies: `npm install`
3. Start the server: `npm start`
4. Open `http://localhost:3000` in your browser.

## Features
- Tracks winning/losing streaks by team.
- Displays results in a simple web interface.
- Built with HTML, JavaScript, and Node.js.

## Future Improvements

- Visualize streaks with charts.
